# MiMO — Moments of You & Me

쿠션형 동반 로봇 MiMO 프로젝트 소개 웹사이트입니다.

## 배포

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 게시합니다. 별도의 설치나 빌드 과정이 필요하지 않습니다.

저장소에 수정 사항을 올리면 웹사이트가 자동으로 갱신됩니다.

## 로컬에서 보기

이 폴더에서 `python3 -m http.server 8000`을 실행하고 브라우저에서 `http://localhost:8000`을 엽니다.

## 포함 파일

- `index.html`: 페이지, 스타일, 상호작용
- `fonts/`, `img/`, `v3/`: 글꼴, 이미지, 영상
- `mimo_sound.mp3`: 인터랙션 사운드
- `.nojekyll`: 파일을 가공하지 않고 그대로 게시하는 설정

## 방명록

Supabase 프로젝트 `mimo-guestbook`에 연결됩니다. 이름·편지·사진은 공개되며, 작성할 때에만 익명 방문자 계정이 만들어집니다.

- Karyn / Jinhee 선택, 이름 24자, 메시지 200자, 압축 사진 약 80 KB 이내
- 작성 브라우저에서 본인 편지 숨기기(삭제), 브라우저 데이터 삭제 시 작성자 권한 소실
- 운영자 삭제: `guestbook-admin.sql`의 코드를 바꿔 Supabase SQL Editor에서 한 번 실행하면, 방명록 편지 카드의 × 버튼을 누르고 그 코드를 넣어 어떤 편지든 숨길 수 있습니다. 실제 코드는 저장소에 올리지 마세요.
- 운영자는 Supabase Table Editor의 `mimo_letters`에서 `deleted_at`에 날짜를 넣어 편지를 숨길 수 있습니다. 값을 비우면 복원됩니다.
- 방문자별 30초 전송 간격 및 하루 20개 제한. CAPTCHA는 아직 연결하지 않았으므로 의도적인 익명 계정 반복 생성까지 차단하지는 않습니다.
- 최근 200개를 불러오며, 열린 화면에서는 30초마다 새로 확인합니다.
- 삭제된 편지는 공개 목록에서 숨겨지고 데이터베이스에는 보관됩니다.
- 브라우저에는 공개용 publishable key만 포함됩니다. 데이터 접근은 서버의 RLS 정책으로 제한합니다.
- 사진은 원본의 압축 기능을 이용해 편지와 함께 저장됩니다.

## 기타

MiMO 대화는 미리 작성된 응답으로 작동합니다. 실제 AI 답변은 별도 연결이 필요합니다.
Google Fonts, hls.js, Supabase JS CDN을 사용합니다.
