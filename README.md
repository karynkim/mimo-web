# MiMO — Moments of You & Me

쿠션형 동반 로봇 MiMO 프로젝트 소개 웹사이트입니다.

## 배포

GitHub Pages에서 `main` 브랜치의 루트(`/`)를 게시합니다. 별도의 설치나 빌드 과정이 필요하지 않습니다.

저장소에 수정 사항을 올리면 웹사이트가 자동으로 갱신됩니다.

## 로컬에서 보기

이 폴더에서 `python3 -m http.server 8000`을 실행하고 브라우저에서 `http://localhost:8000`을 엽니다.

## 포함 파일

- `index.html`: 페이지, 스타일, 상호작용
- `fonts/`, `img/`, `v3/`: 글꼴, 이미지, 영상
- `mimo_sound.mp3`: 인터랙션 사운드
- `.nojekyll`: 파일을 가공하지 않고 그대로 게시하는 설정

## 현재 기능 범위

원본은 Claude 전용 `window.claude` 서비스에 방명록과 AI 대화를 연결합니다. GitHub Pages에서는 해당 서비스가 제공되지 않으므로:

- 프로젝트 소개, 이미지, 영상, 소리 및 화면 상호작용은 정적 웹사이트로 제공됩니다.
- 방명록은 저장되지 않으며 전송 버튼이 비활성화됩니다. 실제 공유 방명록을 사용하려면 별도의 저장 서비스 연결이 필요합니다.
- MiMO 대화는 원본에 포함된 미리 작성된 응답으로 작동합니다. 실제 AI 응답에는 별도 서버 연결이 필요합니다.
- 외부 Google Fonts와 hls.js CDN을 사용합니다. 영상은 HLS 재생 실패 시 MP4로 전환됩니다.

원본 디자인과 미디어는 유지하고, 외부 배포에서 방명록을 사용할 수 없다는 안내만 수정했습니다.
